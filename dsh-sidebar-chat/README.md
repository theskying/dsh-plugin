# DSH 侧边栏对话

针对 DSH `0.2.1-rc.2` 的本地插件。当前版本仍为验证版，未发布市场。

## 行为

- 右侧开始页打开独立侧栏；沿用原生会话、模型、权限、输入框。
- 身份为主会话 ID + 原生持久化 contentId。刷新不会生成新的随机关联；原生布局负责恢复标签。
- 新侧栏继承创建时主会话的权限，之后独立调整。默认名称为「侧边栏1-主对话标题」。
- 原生标签右键菜单提供重命名；原生关闭处理器先保留标签，在 DSH 页面内显示跟随主题的确认弹窗（取消／关闭并删除）。Host 清理成功后才关闭标签；失败在弹窗内显示，可重试，不弹系统确认框。
- 生命周期从创建算起 12 小时，不因续聊或重启延期。Host 每分钟扫描，客户端按到期时间移除标签；停机期间无法执行删除，启动后补清理。
- 插件卸载只释放句柄，不把未到期会话当作用户关闭。
- 主对话可使用 `/sidebar-reference`，多条时使用完整标题或 session ID 选择；不自动回写主会话。已主动复制进主会话的历史快照不会被侧栏删除回溯抹除。
- 自动主上下文只带直接用户/助手文本及检查点；最多 12000 字符且 16 KiB UTF-8，使用已提交引用作为游标，未变化时跳过、变化后增量注入，不生成全文 spill。详细工具结果通过 `sidebar_read_main` 读取。

## 删除与数据边界

DSH 没有通用会话删除接口。本版本仅适配已核实的 JSONL 后端：停止并释放插件自己创建或恢复的 AgentHandle，读取原始 header 核对目录，持有写租约执行定向日志目录维护，检查存储不再可见，并清理精确投影缓存记录。失败保留 closing 登记，下轮继续处理；不假报成功。

不能把以下内容说成已全部擦除：用户通过工具写入的工作区文件、共享附件、外部服务记录、先前复制到其它会话的快照，以及旧版本 spill 文件。这些有不同所有者，不能由插件按路径猜测批量删除。新自动上下文不再产生全文 spill。

已关闭标签保留不含正文的身份墓碑，防止旧浏览器布局在重启后把它重新创建；会话正文不保存在墓碑中。该小型元数据目前不按时间回收。

## 兼容与尚需验收

- 旧版本随机 tabId 无法可靠对应原生 contentId，不按顺序或名称猜测迁移。旧数据保留原到期时间；若旧 Agent 由其它运行时持有，清理会明确失败并保留登记，需要重启后释放旧所有权。
- 原生 `@` 候选发现没有插件专属过滤扩展点。本插件在模型步骤接收引用时拒绝过期、关闭或不属于当前主对话的侧栏，但不能保证其它会话的候选列表完全不显示有效侧栏。此限制不是文件保密或 OS 隔离。
- 原生替换标签操作遇到异步清理时先被同步关闭保护暂停；成功关闭旧标签后，需要重新执行打开动作。
- 模型选择沿用 DSH 自带行为，可能修改未来新会话默认模型；不会改变当前主会话模型。
- 本地回归测试不等同真实浏览器验收。仍需在现有 DSH 页面确认右键菜单、关闭确认、重启恢复、到期消失、明暗主题，以及真实关闭后的原生引用不可达。

```sh
node --test --test-timeout 8000 tests/*.test.mjs
npm pack --dry-run --ignore-scripts --json
```

删除测试使用自行创建的独立临时目录并清理，不删除用户会话。发布白名单包括所有运行时模块；本地仍为 `private: true`，不会自动发布。
